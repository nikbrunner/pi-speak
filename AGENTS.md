# pi-speak — Project Context

## What This Is

A **Pi coding agent extension** that adds voice readback via Unreal Speech TTS. Not a standalone app — runs inside Pi.

## Platform

macOS only. Platform abstraction exists (`src/platform.ts`) for future Linux/Windows support.

## Project Skills

See `.agents/skills/` for project-specific knowledge.

## Packaging

Distributed via `pi install npm:@nikbrunner/pi-speak`. See **README.md** for full details.
